# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [0.3.0] — 2026-09-25

### Добавлено

- `useEmojiData` возвращает `loading` и сбрасывает данные при смене `deps`.
- Меню тонов кожи управляется с клавиатуры (стрелки, Home/End, Escape).

### Исправлено

- `columns <= 0` больше не зацикливает раскладку сетки; некорректные
  `columns` и `cellSize` приводятся к безопасным значениям.
- `sameEmojiValue` больше не путает id серверного эмодзи с его суффиксом.
- Смена `recentKey` перечитывает «Недавние» из localStorage.
- Активная ячейка сбрасывается при смене данных и раскладки.
- Escape закрывает открытое меню тонов, не закрывая весь пикер.
- Анимация скролла учитывает `prefers-reduced-motion`.
- `customEmojiUrl` клампит размер картинки к диапазону Discord.

## [0.2.0] — 2026-09-22

### Изменено

- Секция и вкладка серверных эмодзи переехали в начало списка.
- Вкладки категорий помещаются в одну строку.
- Фон поповера тонов кожи сделан непрозрачным.

### Производительность

- Плавный доезд до секции вместо нативного `scroll-behavior: smooth`.
- Окно виртуализации пересчитывается в rAF, перерисовка — только при сдвиге.

## [0.1.0] — 2026-09-22

Первый выпуск: виртуализированный эмодзи-пикер на React с вкладками категорий,
поиском по названиям и тегам, тонами кожи, «Недавними» и серверными эмодзи Discord.
Словари ru/en собраны из emojibase-data.
